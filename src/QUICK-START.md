# ⚡ Quick Start Guide

## 🏃‍♂️ Get Running in 3 Steps

### 1️⃣ Install Dependencies
```bash
npm install
```

### 2️⃣ Add Your Images
Place your images in the `/public` folder:
```
/public/Home/Hero-Image.jpg                    👈 Your hero banner
/public/Products/Leather/billfolds/billfolds-01.jpg
/public/Products/Leather/wallets/wallets-01.jpg
... etc
```

### 3️⃣ Run Development Server
```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

---

## 📦 Build for Production

```bash
npm run build
```

The `dist/` folder contains your production-ready site!

---

## 🚀 Deploy (Choose One)

### Easiest: Vercel
1. Push to GitHub
2. Connect to [Vercel](https://vercel.com)
3. Auto-deploys! ✨

### Also Easy: Netlify
1. Run `npm run build`
2. Drag `dist/` folder to [Netlify](https://netlify.com)
3. Live! 🎉
