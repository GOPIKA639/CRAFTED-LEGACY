========================================
⚡ IMPORTANT NOTES
========================================

1. File names are CASE SENSITIVE
   ✅ billfolds-01.jpg (correct - lowercase)
   ❌ Billfolds-01.jpg (wrong - capital B)

2. Use HYPHENS not underscores
   ✅ billfolds-01.jpg (correct)
   ❌ billfolds_01.jpg (wrong)

3. Number format is -01, -02, -03
   ✅ wallets-01.jpg (correct)
   ❌ wallets-1.jpg (wrong - missing zero)

4. Supported formats: .jpg, .jpeg, .png, .webp
   (But the code expects .jpg by default)

5. Recommended image sizes:
   - Hero Image: 1920x1080px (landscape)
   - Product Images: 800x800px (square)

========================================
🔄 AFTER ADDING IMAGES
========================================

For Development (npm run dev):

For Production (npm run build):
- Run: npm run build
- Images are copied to dist/ folder
- Deploy dist/ folder to your hosting

========================================
🆘 TROUBLESHOOTING
========================================

Image not showing?
1. Check file name matches EXACTLY (case-sensitive!)
2. Check file is in correct folder
3. Refresh browser (Ctrl+F5)
4. Check browser console for errors

Still not working?
- Verify folder path: /public/Products/Leather/[category]/
- Ensure file extension is lowercase: .jpg not .JPG
- Try renaming the file to match exactly
